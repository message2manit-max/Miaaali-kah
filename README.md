# How Claude Was Made

A two-minute crayon cartoon, narrated by Claude, about how Anthropic started and how fast it grew.

Open `index.html` in any modern browser and press **Play the story**. It is a single self-contained file with no build step.

- **Look:** everything is drawn live on a canvas in a kid's crayon style, with wobbly "boiling" outlines, scribbled colouring and handwritten text.
- **Narration:** uses the browser's built-in speech voice, with subtitles. Scenes wait for each spoken line, so the pictures stay in sync with any voice speed. With no voice available, the subtitles carry the story.
- **Story (13 chapters):** the 2021 founding, Constitutional AI, holding the first Claude back in 2022, the March 2023 launch, the model releases, the big partners, then hand-drawn charts of revenue run-rate and valuation.
- **Data:** the figures and their sources are listed under the player. The page is fan-made and unofficial.

The handwriting fonts (Gochi Hand and Patrick Hand, SIL Open Font License) are embedded in the page.
